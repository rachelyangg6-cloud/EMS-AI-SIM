# raw/

Put your own source material here: extracted resources (`source-N.md`, from page PNGs, PDF or TXT,
made with `protocol-add-resource`) or extracted SOP notes (`protocol-add-source`).
The ingest pipeline and the `/ingest-source` skill read from this folder.

Everything in this folder except this README is gitignored. Only ingest material you
are licensed to use, and don't commit it: copyrighted source text doesn't belong in a
public repository.
